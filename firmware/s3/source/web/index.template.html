设备与连接

未连接；打开页面不会连接设备或改写寄存器。

开发接口303A:4005，Report ID0／双向10字节。Windows管理播放与录音流。

寄存器读写

输入均为十六进制。连接和查询只读；上电默认初始化由固件完成。

写入后显示真实读回；读回不一致不算成功，不会自动重试或覆盖恢复。RO、W1C、复位等特殊寄存器不适合普通写入核验。

时钟控制

默认固件在启动时输出时钟，并在暴露 USB 前初始化 AC101S 的 USB 播放与人声清晰配置。切换前先停止系统播放和录音；此页不做音频刺激。
