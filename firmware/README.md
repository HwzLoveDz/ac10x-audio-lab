# 默认固件 0.3.3

USB声卡默认播放；人声清晰EQ（180Hz−3dB、2.5kHz+3dB、8kHz+1.5dB，前级−4dB）保持。DAC与Line Out均0dB，解决旧默认叠加36dB衰减导致近乎无声的问题；实际音量由电脑和外接功放决定。麦克风独立录音，监听及数字回环关闭。

Quick Start与启动参数由同一配置生成并比较83项掩码。镜像仅用于已确认的ESP32-S31应用分区；不包含引导、分区表或NVS。固件源码与镜像对应，不含SDK和编译器。AC101S引脚接法见上级HARDWARE-SETUP.md。

本轮没有重新验收MIC噪声、失真、S3实板或校准声压；旧记录仍作为历史证据保留。
