# S31 默认固件 0.3.3

提供 USB 声卡播放、人声清晰 EQ 和独立麦克风录音。DAC 与 Line Out 均为 0 dB，麦克风监听和数字回环关闭。默认音色参数见[Quick Start 说明](../EXAMPLES.md)。

- [应用镜像](默认固件.bin)
- [固件源码](默认固件源码.zip)
- [SHA-256 校验](SHA256SUMS.txt)

镜像用于 ESP32-S31 的对应应用分区。启动配置与 Quick Start 使用同一套默认寄存器参数。

ESP32-S3 使用独立的[固件和接线](s3/README.md)。项目许可见[LICENSE](../LICENSE)，第三方组件沿用原许可。
